# 点菜小程序-家庭版 产品方案

## 1. 产品定位

做给家庭用的饮食决策小程序，不是餐饮外卖系统。

核心目标：
- 每天快速决定吃什么
- 把家庭常做菜和社区菜谱接起来
- 让做饭、买菜、记录、复用形成闭环
- 后续可通过 VIP 和广告变现

## 2. 核心场景

### 首页主入口
“今天做什么”

用户进入后先选：
- 我做过的
- 社区菜谱
- 随机推荐

再按条件筛选：
- 菜系
- 口味
- 耗时
- 人数
- 现有食材
- 忌口

### 家庭做菜
- 选菜
- 加购物清单
- 生成今日菜单
- 做完后记录评分和备注

### 社区菜谱
- 看别人怎么做
- 收藏
- 评论
- 转载/导入到自己的菜谱库

### 导入配方
- 粘贴链接
- 粘贴文本
- 解析食材和步骤
- 保留来源
- 用户确认后入库

## 3. 商业方向

### VIP
可卖的点：
- 去广告
- 云同步
- 高级筛选
- 智能周菜单
- 根据家庭偏好推荐
- 多家庭成员共享

### 广告
建议放在：
- 信息流列表
- 社区页底部
- 非核心操作页

不要插进：
- 做饭步骤
- 购物清单确认
- 今日菜单生成主路径

## 4. 产品边界

先做：
- 家庭点菜
- 菜谱库
- 今天做什么
- 社区菜谱
- 导入配方
- VIP/广告骨架

后做：
- 复杂社交
- 商家入驻
- 外卖/下单
- 重推荐算法
