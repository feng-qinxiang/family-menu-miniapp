### 1.2 阴影 / 渐变 / 特殊手法

- 双层暖阴影(全卡片恒用)：`0 2rpx 6rpx rgba(60,40,20,.06), 0 18rpx 40rpx rgba(120,70,30,.14~.16)`
- 卡片描边：`1rpx solid #f1ece2`
- Hero 双层遮罩：径向 `radial-gradient(rgba(255,180,80,.16))` 放光 + 线性 `黑→透→微黑→深黑`
- 镂空撞色标题：`-webkit-text-stroke: 3rpx #fff`，pop 部分取消描边直显番茄红
- Section 标题左竖线：`::before { width:8rpx; background:var(--pop); }`，eyebrow 恒用 `--gold-deep`
- 暗卡(ink-deep) `::after`：右下圆形 pop，透明度 13~16%
- 玻璃态：`backdrop-filter: blur(8rpx); background: rgba(255,255,255,.16)`

## 五、落地坑与注意事项(合并各模块 notes)

### 5.1 镂空撞色标题
- `-webkit-text-stroke` 在微信小程序 **iOS WebView 支持，Android 部分机型不稳定**。落地方案：
  1. 优先用 `.title-stroke` mixin(text-stroke + transparent fill)；
  2. Android 兜底：用 `text-shadow` 多向白描边模拟，或直接出图(Hero 标题切 PNG/SVG)；
  3. pop 部分用独立 `<text class="pop">` 包裹取消描边。
- 不要依赖 `background-clip:text`，小程序兼容差。

### 5.2 GSAP → WXSS keyframes
- 小程序无法跑 GSAP。所有动效转 WXSS `@keyframes` + `transition`：
  - tapscale：`.tap-scale:active { transform:scale(.97) }` transition .12s；
  - 光标 blink：`@keyframes blink{50%{opacity:0}} animation:blink 1s steps(1) infinite`；
  - FAQ 展开：`max-height` transition；caret `transform:rotate(180deg)`；
  - FAB 显隐 / Toast 进出 / 圆环进度：keyframes + js 切类名。
- 倒计时(cook-mode 计时器、验证码 60s)必须 **js `setInterval` 驱动**，页面 `onUnload` 清除。

### 5.3 图片打包
- 16 张真实菜图位于 `E:/cx/111/点菜小程序-家庭版/artifacts/img/`。
- 设计稿引用 `img/xxx.jpg` → 小程序统一改为 `/assets/img/xxx.jpg`(建议复制到 `miniapp/assets/img/`)。
- 建议 webp 压缩；主包体积上限 2MB，菜图较多时放分包或走 CDN(`background-image:url(网络图)` 需 `downloadFile` 域名白名单)。
- `background-image` 只能用网络图或 base64，**本地图必须用 `<image>` 标签**或转 base64。Hero 大图建议 `<image mode="aspectFill">` 叠加遮罩 view。

### 5.4 scroll-view 横滑
- 家常菜横卡、quick 快捷栏、排序 chip、标签云需 `scroll-view scroll-x`：
  - 容器 `white-space:nowrap`，子项 `display:inline-block`；
  - 关闭滚动条 `::-webkit-scrollbar{display:none}`；
  - 注意 `enhanced` + `show-scrollbar=false`。

### 5.5 safe-area
- 底部粘性按钮 / 自定义 tabbar / footbar / CTA 必须 `padding-bottom: env(safe-area-inset-bottom)`(见 `.safe-bottom`)。
- 全面屏 Hero 顶部 icon 需避开状态栏：用 `wx.getSystemInfoSync().statusBarHeight` 动态 padding-top。

### 5.6 无 DOM / 伪元素限制
- `::before/::after` 小程序 **支持有限**(view 上可用，部分组件不可)。Section 竖线、暗卡圆装饰建议改用真实子 view。
- 遮罩 mask div → `view + opacity`；`position:absolute`/`z-index`/Flex 正常支持；CSS Grid 转 Flex。
- SVG 可内联或转 `<image>`;进度圆环用 SVG stroke-dasharray。

### 5.7 自定义 tabbar
- `app.json` `tabBar.custom: true` + `custom-tab-bar/` 目录。
- 4 主 Tab(home/recipes/menu/me)，indicator 用 pop 色 + 动态 `left`(js 算)。
- 二级页(shopping/recipe-detail 等)**不在 tabbar**，用 `nav-bar` 顶部返回。

### 5.8 微信支付模块特殊规则
- `pages/payment/checkout` **背景 #fff 非 --paper，字体系统 sans-serif 非品牌 serif**，金额黑色 #1a1a1a 62px。
- 生物识别(指纹)→`wx.startSoterAuthentication`；演示环境模拟支付成功返回 orderId + 过期时间。
- 真实支付走 `wx.requestPayment`(需后端统一下单)。

### 5.9 px → rpx 换算
- 基准：`目标rpx = 设计px ÷ 390 × 750`(本文已按此取整)。
- 常用：24px→46rpx、30px→58rpx、40px→77rpx、60px→115rpx、66px→127rpx。
- 字号建议保留偶数 rpx；1px 描边用 1rpx(物理像素)。

### 5.10 接口与数据约定(⚙ 待后端确认)

- 家庭邀请码：`[A-Z0-9]{6}`，24h 有效。

- 二维码：member-invite 内嵌静态 SVG QR(或后端生成)。
