## 结论

三条核心业务（家庭点菜、家庭做菜、社区）均已真实闭环，后端与小程序联调可跑，
剩余阻断项集中在**部署方需要提供的凭据与域名**，而不是功能缺失。

|------|------|------|

## 验证方式

```bash
cd server && ./mvnw test          # 25 个测试类 / 152 项用例，连真实 MySQL
node miniapp/test/static-check.js # 页面四件套 / JSON / WXSS 配平 / TabBar 与 tabs.js 一致
node miniapp/test/dish-logic.test.js
node miniapp/test/kitchen-logic.test.js
node miniapp/test/interaction-audit.js   # 只报告不阻断（按下反馈 / 假可点 / 热区）
```

CI：`server-ci.yml`（`server/**`）、`miniapp-ci.yml`（`miniapp/**`）、
`workflows-ci-lint.yml`（校验工作流 YAML 自身，防止工作流静默失效）。

## 已知边界（有意保留，不是漏做）

- 图片机审 `mediaCheckAsync` 未接，UGC 图片靠「举报队列 + `/admin` 人工下架」兜底。
- 管理员登录复用普通会话 token（`user_session`），未做独立管理员会话类型。
- `/uploads/**` 已支持签名访问，但需部署方设置 `UPLOAD_ACCESS_SECRET`（prod 未设置会启动失败）。
- 静态 rpx 字号未全量收敛到 token（无可读性收益，属命名一致性问题）。
