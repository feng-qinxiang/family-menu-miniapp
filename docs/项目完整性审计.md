# 项目完整性审计

生成时间：2026-06-16  
审计范围：`miniapp/`、`server/`、`docs/`、配置、测试与主链路闭环。

## 结论

项目已从“可演示原型”推进到“主链路可验收 MVP”。当前真实闭环已经覆盖：

1. 登录：游客、微信 code 登录、手机号 OTP 登录。
2. 家庭：创建家庭、邀请码预览、加入家庭、成员展示。
3. 菜谱与点菜：菜谱库、今日菜单、购物清单重建与勾选。
4. 支撑能力：文件上传、意见反馈、通知中心、资料编辑、会员状态开通确认。

仍未产品化的范围主要是微信支付商业化、在线客服、生产短信网关、后台管理台。这些不阻断家庭点菜 MVP，但上线前需要明确版本边界。

## 已补齐项

### 认证体系

- 后端新增 `POST /api/auth/otp/request` 与 `POST /api/auth/otp/login`。
- OTP 写入 `phone_otp` 表，校验成功后签发真实 `user_session`。
- 开发态 `AUTH_DEV_OTP_ENABLED=true` 时固定验证码 `246810` 并通过 `devCode` 回显，便于联调。
- 小程序 `login-phone` 与 `verify-otp` 页面已接真实 OTP 接口。

### 家庭主链路

- 后端新增 `POST /api/family`、`GET /api/family/join-preview`、`POST /api/family/join`、`GET /api/family/invite-code`。
- `user_account.current_family_id` 支持用户切换/加入后的当前家庭。
- 小程序 `family/create` 和 `family/join` 已接真实接口，不再本地放行。

### 上传、反馈、通知

- 后端新增 `/api/upload`，文件落盘到 `UPLOAD_DIR`，通过 `/uploads/**` 访问。
- 后端新增 `/api/feedback`，反馈落 `feedback_ticket` 表。
- 后端新增 `/api/notifications` 与 `/api/notifications/read`，通知落 `notification_message` 表。
- 小程序反馈页、通知页已接真实 API。

### 资料、偏好与会员

- `me/profile-edit` 已接头像上传与 `PATCH /api/auth/me` 保存。
- 偏好画像、做菜记录 TOP 菜支持跳转菜谱详情或搜索页。

- 订单页基于 `GET /api/vip/status` 展示当前开通记录，不再使用固定假流水。

### 演示数据与联动

## 下一步建议

1. 上线前配置真实 `WECHAT_APP_ID` / `WECHAT_APP_SECRET`。
2. 生产短信接入后设置 `AUTH_DEV_OTP_ENABLED=false`。
3. 若要商业化，再接微信支付、订单表与支付回调；否则保持当前“确认开通”边界。
4. 若要运营审核，再补 admin Web 或小程序管理员入口。
