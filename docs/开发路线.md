# 开发路线

## 第一阶段：骨架

- 小程序首页
- 家庭/成员
- 菜谱库
- 今天做什么
- 购物清单

状态：已完成基础页面、游客登录、MySQL 持久化、今日菜单和购物清单闭环。

## 第二阶段：社区

- 社区菜谱流
- 收藏/评论/举报
- 导入链接/文本
- 内容审核
- 社区发帖

状态：已完成。社区帖子浏览、发帖、评论、收藏、举报、审核队列全部闭环。

## 第三阶段：变现

- VIP 权限
- 广告位
- 去广告
- 高级筛选

状态：已完成。VIP 开通页、广告组件（VIP 隐藏）、高级筛选（VIP 门控）全部闭环。

## 第四阶段：增强

- 云同步
- 周菜单自动生成
- 个人偏好学习
- 食材库存联动

状态：已完成。周菜单智能排菜、口味画像统计、食材库存管理+菜谱匹配、VIP 云同步标识全部闭环。

## 先做顺序

1. 定页面和接口
2. 定数据库
3. 做家庭闭环
4. 再做社区
5. 最后做 VIP 和广告
