# MVP 功能清单

## A. 必做

1. 家庭与成员
- 创建家庭
- 加入家庭
- 成员角色

2. 菜谱库
- 新增菜谱
- 编辑菜谱
- 标签
- 口味/菜系/耗时/人数
- 做过记录

3. 今天做什么
- 从“我做过的”选
- 从“社区菜谱”选
- 随机推荐
- 按条件筛选
- 生成今日菜单

4. 购物清单
- 从今日菜单自动汇总食材
- 手动增删
- 标记已购

5. 社区
- 菜谱流
- 收藏
- 评论
- 举报

6. 导入
- 链接导入
- 文本导入
- 来源保留
- 用户确认后保存

## B. 变现

1. VIP
- 去广告
- 云同步
- 高级筛选
- 智能推荐

2. 广告
- 首页信息流广告
- 社区页广告位

## C. 暂缓

- 订单支付
- 商家系统
- 复杂积分体系
- 复杂关系链
- 大模型自动生成全套菜谱
