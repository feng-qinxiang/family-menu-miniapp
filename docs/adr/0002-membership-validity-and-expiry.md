# 会员按有效期售卖，到期降级但不删数据，不做自动续费

接入微信支付时需确定会员的时间模型与到期行为。

**决策**：
1. 会员有期限。家庭会员记录存 `expires_at`，一笔成功支付按套餐时长（月卡 +1 月、年卡 +1 年）在现有 `expires_at` 上**叠加延长**，续费不覆盖。
2. 权益解析以「`expires_at > now()`」判定，取代 `vip_status` 布尔位。
3. 到期自动降级为免费版（广告恢复、增值能力停用），但已有数据全部保留不删。
4. 不做自动扣费续订；到期由用户手动再次购买。

**理由**：贴合「家庭年卡 / 月卡」复购变现主线；到期保留数据是家庭场景刚需（不能因到期删掉用户攒下的菜谱）；连续包月需微信支付分/委托代扣资质，先不引入以降低合规与实现成本。

**影响**：家庭会员表需 `expires_at` 字段；续费逻辑做时间叠加；降级仅切换权益开关，不触碰业务数据。
