# 会员绑定购买者用户，可选共享给当前家庭（取代 ADR-0001）

盘问中模型从「家庭归属」翻转为「购买者归属 + 可选共享」。取代 ADR-0001，部分修订 ADR-0004。

**决策**：
1. 会员资格绑定**购买者 user**。会员表（重命名/重建为 `user_membership`）以 payer_user_id 关联，含 expires_at、current_plan、share_scope、updated_at。订单 `payment_order` 记 payer_user_id（下单即购买时所属 family_id 仅作快照参考，不决定归属）。
2. 每份会员带 `share_scope` 开关：`SELF`（仅购买者本人享有）/ `FAMILY`（共享给购买者**当前所属**家庭的全体成员）。开关可由购买者切换。
3. VIP 判定：用户本人持未过期会员，**或** 其当前家庭存在成员持未过期且 `share_scope=FAMILY` 的会员。
4. 购买者退出家庭 → 会员随人走，原家庭失去该份共享；加入新家庭且 share_scope=FAMILY 则照亮新家庭。
5. 购买权对**任意 ACTIVE 成员**开放，与角色无关（场景：管理员没注意到过期，普通成员补位购买并共享）。
6. ADR-0002（有效期/叠加续费/到期降级不删数据）、ADR-0003（模拟支付、模型做实）继续有效。

**理由**：贴合用户「订单在谁身上、会员就在谁身上，但能共享给整个家庭」的诉求；共享做成显式开关而非自动，给「我买的只想自己用」留出口。掏钱不设门槛，故购买权不做角色门控。

**影响**：会员表主关联由 family_id 改为 payer_user_id，新增 share_scope 列；VIP 解析逻辑改为「本人 OR 当前家庭共享成员」两路判定；前端需提供共享开关 UI。
