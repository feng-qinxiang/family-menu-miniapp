- 普通机型：iPhone 12/13 (Pro)，390 × 844，浅色。
- 窄屏机型：HUAWEI Mate X6 外屏，346 × 781，深色；四页均临时设为应用的大字模式，逐张查看截图。
- 实际输入「红烧肉」并触发键盘确认：1 条结果；点击清空：恢复 16 条。不是只直接调用筛选函数。
- 原生操作发现 Page 包装函数会丢失防抖函数的 `.cancel` 属性，修为每个页面实例独立持有；测试替身也补上原生方法包装行为。
- 份数分别调至 1 和 20 后实际点击边界按钮，份数不越界；五花肉用量分别保持 125 克和 2500 克。
