管理端界面 · 改前改后

方向跟小程序这次一致：同一套颜色、字体、按钮和表单。一共 7 处改动，每处单独提交，不满意哪一处可以单独退回（跟我说「退回第 N 节」就行）。
截图都是 1440×900 的电脑屏幕，用的是本机的开发数据。功能和数据都没动：13 项点击检查都过了（全程没有发一个修改请求），后台的 61 个接口测试也全过。

管理端现有的 15 个页面

  • 登录
  • 概览：数据看板
  • 内容：内容治理（帖子）、评论管理、举报审核、导入审核
  • 用户：用户管理
  • 家庭数据：家庭与成员、今日菜单、买菜清单、冰箱库存
  • 运营：订单管理、反馈工单
  • 系统：菜谱治理、审计日志

其中 7 个页面是「状态筛选 + 表格 + 行内操作」的列表页，4 个是家庭数据（冰箱库存能编辑，其余只读）。所以前 4 节是全局的样式统一，后 3 节是页面结构的调整。

1. 颜色换成小程序那一套提交 7fe379d

原来是冷灰底、近黑字、砖红。现在跟小程序用同一组颜色：

  • 底色：暖米色（小程序的纸色）
  • 文字：暖墨色
  • 主色：番茄红
  • 辅助色：松绿
  • 「待审核」这类标签：深金色
  • 只换颜色，位置和大小都没动

2. 按钮、筛选标签、输入框统一提交 8dbeef0

照小程序的做法改了这几处：

  • 按钮分三级：主按钮红色实心，一屏最多一个；次按钮白底细边；表格里的操作是文字按钮
  • 「通过 / 恢复」这类正向操作改成松绿色，原来是黑色实心块；「下架 / 封禁」还是红色
  • 筛选标签：浅米色底，选中变深棕，跟小程序的筛选片一样
  • 输入框、按钮、筛选标签、日期框统一 34 像素高，原来 30、32、36 混着用
  • 表头字号跟正文一致，去掉了原来拉开的字距

3. 侧边栏换深棕，只在有待办时显示数字提交 a0eb9a4

侧边栏从墨绿换成小程序的深棕。原来每个入口后面挂一个灰色的「0」，现在只有真有待办时才亮出红色数字，一眼就知道该去哪。行距也收紧了，电脑屏幕上 14 个入口一屏都能放下，「审计日志」不用再滚侧栏才能看到。

审计日志（注意左下角）

4. 登录页换成同一套颜色提交 8c79f14

左侧品牌区换成跟侧边栏一样的深棕，勾号和光晕改成小程序的浅金色。右侧表单在第 1、2 节已经跟着变了。

5. 「导出 Excel」都放到筛选行最右边提交 65b0d34

原来 9 个页面的导出按钮在说明文字右上角，评论和用户这 2 个页面在筛选行里，位置不统一。现在全部放在筛选行最右边，筛选完顺手就能导出。按钮做的事没变。

审计日志

内容治理

6. 表格：编号列收窄，家庭名改成可点的文字提交 e3651b8

编号列原来又宽又靠右，勾选框和编号之间空出一大截，标题和作者被挤到右边。现在编号列只占自己那么宽，颜色也放淡了。今日菜单、买菜清单、冰箱库存里的家庭名原来每行都是一个带边框的按钮，现在改成松绿色文字，点了照样打开家庭详情，行也矮了，一屏能多看几行。

7. 数据看板：「待处理」挪到最上面提交 3b924e2

打开后台第一件事是看有没有要处理的，所以「待审帖子 / 评论 / 举报 / 反馈 / 导入」这一排挪到了最上面，指标放第二排，各加了一个小标题。全部为 0 时标题后面写「都处理完了」；有待办时卡片照旧变红，点了直接跳到对应列表。
