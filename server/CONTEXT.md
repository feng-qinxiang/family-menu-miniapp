# Server

后端领域上下文：承载家庭、菜谱、菜单、社区、会员与支付的核心规则。

## Language

### 会员与支付

**Membership（会员资格）**：
绑定于**购买者 user** 的付费资格，落库为 `user_membership` 表（payer_user_id、expires_at、current_plan、share_scope）。会员随购买者本人走。`user_account` 上不再存任何会员字段。
_Avoid_: VIP（仅作面向用户的展示词，不作领域主体）、家庭会员、vip_status

**ShareScope（共享范围）**：
一份会员的共享开关。`SELF` = 仅购买者本人享有；`FAMILY` = 共享给购买者**当前所属**家庭的全体成员。购买者可切换；换家庭时共享随人转移。
_Avoid_: 公开、私有

**VIP 判定**：
某用户享有会员权益，当且仅当——本人持未过期会员，**或** 其当前家庭存在成员持未过期且 share_scope=FAMILY 的会员。判定规则：
- 多份共享叠加：家庭享有的有效期取所有共享会员中最晚的 expires_at（max）。
- 实时解析、不缓存：共享者退出家庭即刻失效；VIP 状态每次现算「当前家庭有无有效共享」。
- 购买者本人恒享有：无论 share_scope 为 SELF 或 FAMILY，购买者自己始终享有；share_scope 仅影响家庭其他成员。
_Avoid_: 直接读单一布尔位、缓存 VIP 态

**Family（家庭）**：
菜单、购物清单、成员的归属主体，并作为会员**共享**的受益范围。家庭本身不拥有会员（会员归购买者）。
_Avoid_: 账户、组、团队

**有效期（expires_at）**：
会员资格的截止时刻。是否享有会员权益由「expires_at > 当前时间」判定，而非布尔开关。一笔成功支付按套餐时长在现有有效期上**叠加**（续费不覆盖）。
_Avoid_: vip_status 布尔位（已弃用）

**降级（到期失效）**：
有效期过后会员自动回到免费版：广告恢复、高级筛选与云同步等增值能力停用，但已有数据（菜单、菜谱、库存等）一律保留不删。
_Avoid_: 注销、清除

**Admin（管理员角色）**：
家庭管理能力的持有者（加人、移除成员、提升/降级管理员）。owner（创建者）默认即 admin。**与购买权无关**——任意 ACTIVE 成员均可购买会员。
_Avoid_: 用 admin 作购买门控

**PaymentOrder（支付订单）**：
一次会员购买的记录主体。后端生成唯一商户订单号（out_trade_no），记录 payer_user_id、下单时所属家庭快照、套餐、金额（分）、支付方式与状态。是会员开通的唯一凭据来源。
_Avoid_: 交易、流水、purchase

**开通凭据（唯一真相来源）**：
家庭有效期的延长**只能**由订单进入 PAID 终态触发。当前阶段 PAID 由模拟开通端点（payment_method = MOCK）置位；未来由微信异步 notify 验签通过触发。前端的支付回调只刷新 UI，永不作为开通依据。
_Avoid_: 前端确认开通

**订单状态机**：
PENDING（已下单待支付）→ PAID（已到账，触发开通）；旁路终态 CLOSED（超时关单）、REFUNDED（退款）。同一 out_trade_no 的重复开通请求幂等，不重复延长有效期。

**Plan（套餐）**：
后端权威定义的会员档位（如 monthly = 30 天、annual = 365 天），由 `plan_code` 标识。下单只传 plan_code，金额与时长一律后端按 code 查出，前端传来的价格一律忽略。金额以 `amount_fen`（分，整数）存储，杜绝浮点。MVP 阶段套餐目录为后端硬编码常量。
_Avoid_: 前端传价、前端定时长、用元/浮点存金额

### 运营管理台

**Operator（运营管理员）**：
持有 `user_account.is_admin = 1` 的账号，可访问 `/api/admin/**` 与 `/admin` 后台。
与家庭内的 owner/admin（家庭管理角色）是**两套概念**：前者管平台内容与用户，后者管自己家庭的成员。
首个运营管理员由部署方通过环境变量 `ADMIN_OPENIDS` 白名单播种（只升权不降权，留空则不播种）。
_Avoid_: 把家庭 admin 当运营管理员、在代码里硬编码管理员 openid

**管理员登录**：
后台登录走「手机号 + 验证码」，但只对 `is_admin = 1` 且已绑定手机号的账号签发会话。
普通用户即使验证码正确也拒绝。后台 token 与小程序 token 同源同表，但登录类型为 `admin`。
_Avoid_: 后台复用小程序 token 模型、给未绑定手机号的管理员开登录

**审计日志（AdminAuditLog）**：
管理员每一次写操作（授予/回收管理员、下架内容、处理工单、人工开通会员）都落一条记录：
操作人、动作、对象、详情、结果、时间。只增不改不删，用于事后追责与合规。
_Avoid_: 管理操作不记日志、日志可被后台修改

**封禁（BAN）**：
`user_account.status = BANNED` 表示账号停用。封禁即刻吊销全部会话且无法再登录；解封恢复 ACTIVE。
管理员账号不可封禁（须先回收管理员权限）。_Avoid_: 封禁后残留有效会话、封禁管理员把自己锁死

**关单/退款（CLOSED / REFUNDED）**：
订单旁路终态由运营后台触发：关单仅限 PENDING；退款仅限 PAID，并按订单时长扣减购买者会员有效期（不低于当前时刻）。真实资金退款在商户平台人工操作。_Avoid_: 退款不回收权益、终态再流转

**会话 token 存储**：
`user_session.token` 存的是 bearer token 的 SHA-256 摘要，**不存明文**；明文只在登录响应里返回一次。
支持 `POST /api/auth/logout` 吊销；回收管理员会同时吊销该用户全部会话。
_Avoid_: 明文 token 落库、token 永久有效无法吊销
